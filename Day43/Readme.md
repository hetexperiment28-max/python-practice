## 🛠️ Project: Library Management System

A small library wants software to manage books and members.

# Requirements 

The library should be able to:

Add books
Show available books
Borrow a book
Return a book

There are two kinds of members:

Student
Teacher


# Minimum Features

Your project should include:

At least 3 classes
At least 1 inheritance relationship
At least 1 overridden method
Use one list to store books
Use constructors
Use objects, not dictionaries
